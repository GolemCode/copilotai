# Front Copilot AI (React + Vite)

Interface du copilote financier : portefeuille, performance réelle, risque, Monte Carlo,
stress tests, optimisation de Markowitz et assistant RAG.

Voir le [README principal](../README.md) pour l'architecture, la méthodologie et le démarrage.

```bash
npm install
npm run dev     # http://localhost:5173 ; /api et /ws sont relayés vers VITE_API_TARGET (http://api:8000 par défaut)
npm run build
```
